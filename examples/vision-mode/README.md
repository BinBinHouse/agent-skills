## 保留了什么

- 标题：远景模式
- 核心主张：释放芯片的极限潜能，综合服务业务实体
- 三段结构：联合运营 → 性能优化 → Token 工厂/算力管控
- 关键技术：CPU/GPU/NPU、调度与吞吐、实时性/控制周期、端侧推理/功耗、多源采集/建模分析/智能诊断、物理隔离/逻辑隔离和租户级审计

## 做了什么调整

- 将简单倒三角重新设计为带有清晰层次的三段漏斗。
- 保留蓝紫标题母版视觉规范，调整信息层级和间距。
- 把服务器端、机械臂端、终端等内容整合为图文信息区。
- 采用独立机器人插画与眼睛图标，同时尽量保留可编辑的文字和结构对象。

**实际编辑能力检查：** 此提供的 `.pptx` 有 1 页，含 89 个幻灯片对象，其中 25 个有文本的对象和 2 张独立图片。部分视觉元素属于形状组合或图片，并非所有像素都可逐项编辑。

**注意：** “美化前”是原始用户截图，“美化后”来自提供的 PPTX 实际导出，不是 AI 设计效果图冒充成品。效果会因具体模型、工具和字体环境不同而变化。
