# PPT Beautification Workflow — 单页PPT美化 Agent Skill（v1.2）

> **范围明确**：专注于“已有一页 PPT / PPT截图 / 单页PPT文件”的美化与可编辑重建，不默认扩展为整套演示文稿。

## 这个版本更新了什么？

v1.2 重点修了两类问题：

1. **明确区分“美化”与“还原”**  
   如果提示词只写“做成可编辑 PPT”，模型可能更偏向“还原”；如果你希望更好看，需要明确写“美化”“按工作流”“先出效果图再重建”。

2. **禁止把母版装饰直接截图裁切贴回 PPT**  
   左上角标题装饰、顶部横线、右上角波浪/弧形装饰等，统一按“母版元素”处理：优先复用原PPT中的母版/形状；没有源文件时再重绘，而不是截图硬贴，避免叠字、白边和残缺。

同时，v1.2 增强了对 **PPT 文件输入** 的支持：
- 如果你上传的是 PPT / PPTX，通常比只上传图片更好；
- 因为它可以直接提取真实文字、数字、母版、标题样式和固定装饰；
- 同样可以执行美化，而且更容易复用原模板风格。

---

## 你可以用它做什么？

- 美化单页 PPTX 或单页截图：整理排版，但默认保留原始文字、数字、LOGO 和标题样式。
- 根据参考样式先做一张视觉设计稿；确认后继续生成可编辑 PPTX。
- 将一张已有美化图或截图等比例还原为真正可编辑的 PPT。
- 保留原生可编辑的正文、数字、卡片、箭头等元素。
- 在真实 PPT 底板定稿后，独立生成高质量图标，并按实际 RGB / 透明背景进行无缝嵌入。
- 必须把 PPTX 真正渲染成 PNG 检查，发现溢出、错行、色差、母版装饰重叠就修复。

不默认处理整套母版库、批量美化几十页或从零撰写整套 PPT。

## 使用方式

## 模式 1：美化重构（推荐）
适用于：
- 页面内容基本已有，但版式普通；
- 你希望先出一张更好看的效果图，再转成可编辑 PPT。

**推荐提示词**：

> 使用 `ppt-beautification-workflow` 美化这一页 PPT。沿用现有模板和原文，先给我美化效果图；确认后继续制作可编辑 PPT。不要只做截图还原。左上角标题装饰、顶部横线、右上角波浪装饰都视为模板母版元素，请重建或复用，不要直接截图裁切复用。

---

## 模式 2：等比例还原
适用于：
- 你已经有一张满意的图片或效果图；
- 你只是希望把它变成可编辑 PPT，不做额外设计。

**推荐提示词**：

> 使用 `ppt-beautification-workflow` 将这一页等比例还原为可编辑 PPT，尽量保持视觉一致，不做额外美化。左上角标题装饰、顶部横线、右上角波浪装饰属于母版元素，请不要直接截图裁切粘贴，尽量复用原PPT母版或用可编辑形状重建。

---

## 模式 3：你上传的是 PPT 文件
这是推荐方式之一，通常效果更稳定。

**推荐提示词**：

> 我上传的是 PPT 文件，请优先复用其中的母版样式、标题样式和固定装饰，再对指定这一页进行美化。输出可编辑 PPT 和实际预览图。

### 为什么上传 PPT 会更好？
因为 Skill 可以直接读取：
- 真实文字
- 数字
- 字体层级
- 卡片结构
- 标题样式
- LOGO
- 母版背景
- 固定装饰元素

这样既能保持原主题风格，也更容易避免截图裁切带来的重叠和白边问题。

---

## 一个很重要的提醒：美化 vs 还原，一定要说清楚

如果你只说：
> 帮我把这一页变成可以编辑版本的 PPT 吧。

模型可能理解成：
- **等比例还原**

而不是：
- **先美化，再重建**

所以如果你想要更好看的结果，请尽量写：
- “请美化这一页”
- “请严格按工作流来做”
- “先给我一张美化效果图，再做可编辑 PPT”

## 与 ChatGPT Presentation Template 的区别

这个目录是**通用 Agent Skill**，内部名称 `ppt-beautification-workflow`。  
它不是 ChatGPT `@Presentations` 模板库里的 `artifact-template-ppt-beautification-workflow`。

区别可以简单理解为：

- **Agent Skill 版**：规则驱动，更适合你在不同 GPT / Agent 环境中复用；
- **Presentation Template 版**：更偏模板调用，适合在 ChatGPT Work / Presentations 中点选模板使用。

两者可以共享相同思路，但目录结构和底层文件不一定一样，不能直接互相覆盖。
