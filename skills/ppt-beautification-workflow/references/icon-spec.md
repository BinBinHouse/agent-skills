# 单页PPT图标补全规范

在最终卡片 RGB 确认后再生成图标。

| 项目 | 默认要求 |
|---|---|
| 尺寸 | 同组 1:1，推荐 1024×1024 |
| 内圆占比 | 同组统一，建议占画布 75%–82% |
| 主体占比 | 相同视觉重量；非机械等宽 |
| 中心 | 圆心、主体视觉中心均统一 |
| 颜色 | 蓝/紫渐变、白色符号与参考图协调 |
| 圆外背景 | 透明优先；不透明则使用最终区域真实 RGB |
| 质量 | 高清、边缘干净、可等比例缩放 |

常见对应关系：
- 白色正文背景：RGB(255,255,255)
- 浅蓝卡片：RGB(233,242,255)
- 浅紫卡片：RGB(244,239,255)

注意：图片文件是正方形不代表图标视觉尺寸一致，必须比较其**内圆直径和主体占比**。若“透明”实为棋盘格或白色像素，不要冒充 alpha 透明。**指定精确 RGB 时要用工具验证像素，不要默认生图模型能保证 RGB 精确。**

提示词模板：

> 根据我提供的参考图标单独重生成一个高清、清晰的 PPT 专用图标。使用正方形 1:1 画布，图标内圆居中，圆直径与同组其他图标一致，主体视觉大小一致，整体蓝紫渐变和描边风格一致。圆外优先真正透明 PNG；若指定不透明则圆外每个像素精确使用 RGB(R,G,B)。不要文字、阴影外溢或白色方块，便于贴回已完成的 PPT 底板。
