# 单页 PPT 美化工作流（v1.2）

## 唯一任务

每次**只负责一页**既有 PPT 的美化或还原，不自动扩展为整套 PPT、美化模板库、报告写作或批量母版管理。用户已有内容是事实来源；用户已有模板/母版是视觉来源。

目标产物：
1. 美化效果图（设计稿，可选但推荐）
2. 最终可编辑 `.pptx`
3. 实际 PPT 渲染预览图

复杂装饰和图标可以是独立 PNG/SVG，但**整页不能是不可编辑的大图片**。

---

## 0. 先判定任务模式（非常重要）

在开始前，必须判断当前任务属于哪一种：

### A. 美化重构模式（默认推荐）
当用户出现以下意图时，进入**美化重构**：
- “美化这一页”
- “按工作流来做”
- “先出效果图再做 PPT”
- “不要只是还原”
- “更好看一点 / 更专业一点 / 更像模板一点”

执行方式：
- 先做一张美化效果图（设计稿）；
- 用户确认后，继续重建可编辑 PPT；
- 若用户明确说“无需中途确认，一次做完”，则允许一次性走完整个流程。

### B. 等比例还原模式
当用户出现以下意图时，进入**等比例还原**：
- “还原成可编辑 PPT”
- “按图片重做”
- “尽量保持一致”
- “不做额外美化”
- “按照这张效果图直接做 PPT”

执行方式：
- 重点是**忠实还原**；
- 不主动改变结构和风格；
- 但仍然要避免直接贴整页截图冒充可编辑 PPT。

### C. 表述不清时的处理
如果用户只说：
- “帮我做成可编辑 PPT”
- “把这一页转成 PPT”

而没有说明是“美化”还是“还原”：

1. **优先追问一句**：
   > 你是要我“等比例还原”为可编辑 PPT，还是“先美化再重建”为可编辑 PPT？
2. 如果当前流程不适合追问，且此 Skill 被明确以“美化工作流”调用，则**默认进入美化重构模式**。

### README中必须提醒的使用差异
如果用户只是写“变成可编辑 PPT”，模型可能倾向于执行“还原”；
如果用户希望更好看，提示词中必须明确写出“美化”“按工作流”“先出效果图再重建”。

## 一、理解输入与锁定边界

### 1. 输入优先级
优先级从高到低如下：

1. **原始 PPTX / 单页 PPT**：
   - 用来提取真实文字、数字、表格、排版结构、主题字体、母版和固定装饰；
   - 如果用户上传的是 PPT 文件，这通常比截图更好，因为可以直接复用母版样式和真实文本。
2. **单页截图 / PNG / JPG**：
   - 用来对照当前视觉效果；
   - 如果没有 PPTX，只能依据截图重构。
3. **用户指定的模板页 / 参考风格图**：
   - 用来控制视觉方向，不改动事实内容。

如果同时给出 PPTX 与截图：
- **PPTX 是内容真源与母版真源**；
- 截图是视觉对照；
- 不要反过来只依赖截图裁切。

### 2. 对用户上传 PPT 的处理原则
如果用户以后上传一页 PPT 或整份 PPT：
- **效果通常会更好**；
- 应优先复用：
  - 标题样式
  - 页眉横线
  - LOGO
  - 右上角装饰
  - 配色
  - 母版背景
- 如无特殊要求，尽量沿用用户已有母版风格，而不是重新发明一套完全不同的主题。

### 3. 默认保留与默认不动的内容
默认只改**正文排版和信息组织**；以下内容若无用户要求，优先保留：
- 标题栏
- LOGO
- 角标
- 底板
- 固定页眉/页脚
- 现成模板装饰

不要自作主张：
- 大幅删除文字
- 改掉用户原有的主题装饰
- 加入巨大圆形、渐变光球等无关装饰覆盖原内容

### 4. 锁定事实内容
必须锁定：
- 标题
- 数字
- 技术名词
- 人物/公司名
- 金额
- 百分比
- 公式
- 核心逻辑

默认不大幅删减文字。内容拥挤时应：
1. 先调整结构、字号、留白、分组；
2. 再考虑适度压缩表述；
3. 如必须拆页，需征求用户同意。

## 二、模板母版元素处理规则（非常重要）

以下元素视为**模板母版 / 固定装饰元素**：
- 左上角标题图形组（色块、短斜杠、小装饰）
- 顶部横线
- 右上角波浪 / 流线 / 弧形角饰
- 固定底纹 / 页脚装饰
- 页面四角的模板化背景图案

### 处理原则
这些元素**禁止**从原始截图中直接裁切后贴回最终 PPT。必须按以下优先级处理：

1. **优先直接复用用户 PPTX 中已有的母版元素 / 可编辑形状**；
2. 若没有源文件，则用基础形状、曲线、色块重新绘制；
3. 只有在无法可编辑重建时，才允许使用独立透明 PNG，但必须放在背景层且不得遮挡正文。

### 明确禁止行为
- 禁止把页面边角截图直接当装饰贴回去；
- 禁止把裁切残缺的左上角、右上角图块直接覆盖到新页面；
- 禁止母版装饰压住标题、正文、数字或图片主体；
- 禁止产生白边、锯齿、截断、叠字。

### 布局要求
- 所有母版装饰放到**背景层/底层**；
- 标题和正文必须位于其上层；
- 右上角装饰不得压住标题行；
- 左上角标题装饰组不得与标题文字重叠。

### 边缘识别豁免区
分析截图时，应将页面四周约 5%–8% 的边缘区域视为**模板装饰候选区**。该区域中的色块、弧线、角饰，不应默认视为正文内容，也不应直接截图复用。

## 三、先做单页美化效果图（美化模式下）

1. 参考原页全部核心信息，设计**一张** 16:9（或与原页比例一致）的效果图。
2. 提升以下维度：
   - 层次
   - 对齐
   - 间距
   - 字号层级
   - 卡片结构
   - 重点数字
   - 信息分组
3. 避免：
   - 简单粗暴把内容硬改成三张卡片
   - 过度删减原文
   - 与原主题无关的炫酷装饰
4. 效果图中的中文可能有误字；**最终 PPT 的正文内容必须回到原始资料核对**。
5. 设计稿只用于确定视觉方向，不能把整页设计稿直接贴进 PPT 里冒充可编辑版本。
6. 如果当前没有生图能力，可以先用原生 PPT 形状搭建一个可编辑草版并渲染出视觉稿，但不能谎称“已经完成生图”。

---

## 四、可编辑 PPTX 重建（重中之重）

### 1. 美化模式下
用户确认视觉稿后，立即开始真正的 PPTX 重建，尽量与确认稿在以下方面保持一致：
- 版式
- 比例
- 字体层级
- 主配色
- 信息块位置

### 2. 还原模式下
若用户要求等比例还原：
- 直接进入可编辑重建；
- 重点保持与原图一致；
- 但同样要遵守“母版元素禁止截图裁切复用”的规则。

### 3. 搭建顺序
按以下顺序搭建页面：
1. 页面尺寸与背景 / 母版
2. 标题区
3. 卡片 / 模块 / 漏斗 / 流程图
4. 正文 / 数字 / 表格 / bullets
5. 分隔线 / 连线 / 标注
6. 图标占位

### 4. 可编辑性要求
以下元素必须优先使用 **PowerPoint 原生可编辑对象**：
- 标题
- 正文
- 数字
- 卡片
- 表格
- 流程
- 箭头
- 分隔线

以下元素允许作为独立图片存在：
- 复杂机器人插画
- 难以矢量重建的装饰插图
- 单独高清图标（后置插入）

### 5. 关键检查点
必须检查：
- 关键数字（如“2000万”“900万”“5%”）不拆行
- 文本不溢出卡片
- 不出现大量巨大椭圆 / 遮挡层
- 字体缺失时使用可靠中文字体，并检查实际渲染
- 标题、内容、图形层级正确

### 6. 禁止事项
- 不得把整页生图结果贴进 PPT 来假装可编辑；
- 不得只输出 PPTX 文件却不检查实际渲染效果。

---

## 五、复杂图标后置生成

当效果图中的图标好看，但 PPT 原生形状难复刻时：

1. **先完成无图标版的真实 PPT 页面，并预留精确位置**；
2. 读取该位置的卡片 / 背景实际 RGB；
3. 默认根据设计稿中的对应图标，**单独重新生成高清 PNG/SVG**，而不是从整页截图中硬裁；
4. 同一页同组图标必须统一：
   - 正方形画布
   - 圆形直径
   - 主体视觉占比
   - 居中位置
   - 配色风格
5. 圆外背景优先采用**真正透明 PNG（Alpha）**；
6. 如果必须使用不透明正方形画布，则圆外背景必须匹配最终底板 RGB，例如：
   - `255,255,255`
   - `233,242,255`
   - `244,239,255`
7. 贴回后验证：
   - 无白边 / 灰边
   - 无方底色
   - 尺寸统一
   - 主体不偏心
8. 详细规则见 `references/icon-spec.md`。

## 六、渲染、核验、交付

1. 将 PPTX 实际渲染为 PNG（可使用 LibreOffice 或环境自带渲染工具）；
2. **必须打开预览图检查一遍**，不是仅验证文件是否生成；
3. 与用户确认的效果图或原图并排核验：
   - 布局
   - 标题
   - 卡片比例
   - 主色
   - 内容完整性
   - 换行
   - 图标大小
   - 底板 RGB / 透明背景
   - 母版装饰是否重叠或裁切异常
4. 若发现：
   - 遮挡
   - 数字拆行
   - 画布外对象
   - 图标白边
   - 文字低对比度
   - 左上角 / 右上角母版异常
   必须修完再重新导出。
5. 交付物：
   - `单页主题_可编辑.pptx`
   - `单页主题_实际预览.png`
   - 有图标时可附独立 PNG/SVG 素材包
6. 如果仍有不可解决的细微差异，必须明确说明剩余差异，不能声称“1:1 完全无误”。

## 七、适用范围与限制

### 适用
- 现有单页 PPTX 的美化
- 单页 PPT 截图的视觉重构
- 已确认设计稿转可编辑 PPT
- 高质量图标的补全与替换
- 固定页眉/标题/公司模板的风格沿用
- **从用户提供的 PPT 中复用母版样式后进行单页美化**

### 不默认适用
- 从零编写整套 PPT 文案
- 一次批量处理几十页
- 系统化管理母版库
- 制作视频动画
- 未经许可公开公司机密材料

### 能力边界
- 如果用户上传 PPT 文件，通常效果比纯图片更好；
- 如果只有截图，也能做，但母版复用能力会弱一些；
- 如果工具环境缺失（如不能编辑PPTX、不能渲染、不能生图），必须明确说明，不能虚构产物。

## 八、推荐提示词（要写进 README）

### 1. 要美化
> 使用 `ppt-beautification-workflow` 美化这一页 PPT。沿用现有模板和原文，先给我一张美化效果图；确认后继续制作可编辑 PPT。不要只做截图还原。左上角标题装饰、顶部横线、右上角波浪装饰都视为模板母版元素，请重建或复用，不要直接截图裁切复用。

### 2. 要还原
> 使用 `ppt-beautification-workflow` 将这一页等比例还原为可编辑 PPT，尽量保持视觉一致，不做额外美化。左上角标题装饰、顶部横线、右上角波浪装饰属于母版元素，请不要直接截图裁切粘贴，尽量复用原PPT母版或用可编辑形状重建。

### 3. 有 PPT 文件时
> 我上传的是 PPT 文件，请优先复用其中的母版样式、标题样式和固定装饰，再对指定这一页进行美化。输出可编辑 PPT 和实际预览图。

## 九、反馈修改规则

用户说“这版不行 / 和效果图不一样 / 没有美化效果 / 只是还原了图片”时：
1. 先看实际 PPT 渲染图；
2. 判断问题属于：
   - 模式判定错误（把美化做成了还原）
   - 母版装饰处理错误
   - 图标质量或底色不匹配
   - 文字排版或层级错误
3. 只修改问题最大的部位并重新渲染；
4. 不要无要求整页推翻重做；
5. 若首次提示词不清，应在答复中提醒用户：下次可明确说明“美化”或“还原”。

## 十、便于调用的短口令

> 使用 `ppt-beautification-workflow` 处理这一页。先判断我是要“美化”还是“还原”；如果是美化，先做效果图再重建可编辑PPT；如果我上传的是PPT文件，优先复用母版和真实文字；左上角标题装饰、顶部横线、右上角波浪装饰不要截图裁切复用；复杂图标最后单独生图并按底板RGB或透明背景插入；最终交付PPTX和实际预览图。
