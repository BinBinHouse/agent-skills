# GitHub 公开发布检查

- [ ] 仓库名称与可见性确认；建议先设为 Private。
- [ ] 确认案例中的公司业务信息可以公开，包括“联合子公司”“Token 工厂”及技术方案文字。
- [ ] 确认机器人与眼睛图标、标题装饰等所有引用素材的再分发权利。
- [ ] 若打算开源，请选择并添加合适的 LICENSE；没有许可证时，公开可见不等于允许他人自由复用。
- [ ] 若开源许可与素材权利不同，在案例目录单独说明素材许可。
- [ ] 检查 README 和 PPTX 文件是否包含内部联系人、私人数据、商业秘密或保密内容。
- [ ] 确认案例 PPTX 在常用 PowerPoint/WPS 中打开正常；跨字体环境可能出现小幅重排。
- [ ] 仅发布已测试的 v1.2；此版本一次处理一页，未来批量功能另开发和测试。
- [ ] 不将 ChatGPT 专有 Template Skill 的配置冒称为通用 Agent Skill。
